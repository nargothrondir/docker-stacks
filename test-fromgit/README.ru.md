# Стек: test-fromgit — одноразовый

[🇬🇧 English](README.md) · 🇷🇺 Русский

Одноразовый стек, существовавший ради доказательства, что конвейер From-Git
доходит до **удалённого** хоста: git → Dockhand → Hawser → Docker ноды
(issue #12).

Обычный nginx, без публикуемых портов и томов — безопасно разворачивать где
угодно и удалять после.

## Статус: держится только до сноса лабораторной ноды

Конвейер, который он проверял, доказан и работает в проде, так что смысла у
этого стека больше нет. Он подлежит удалению вместе с лабораторной нодой
(чек-лист сноса: issue #47 в `ansible-playbooks`).

**Перед удалением каталога снеси соответствующий стек в Dockhand** — иначе в
окружении останется стек, исходников которого больше не существует.
